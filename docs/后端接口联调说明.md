## 一、环境准备

### 1.1 技术依赖

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 17+ | Spring Boot 3.x 要求 |
| MySQL | 8.0+ | 推荐 8.0.28+ |
| Maven | 3.8+ | 项目构建 |

### 1.2 克隆与启动

```bash
# 1. 进入后端目录
cd backend

# 2. 配置环境变量（必须）
cp ../.env.example .env
# 编辑 .env 填写真实配置

# 3. 初始化数据库
mysql -u root -p < ../docs/database.sql

# 4. 启动项目（开发模式）
mvn spring-boot:run

# 或打包运行
mvn clean package -DskipTests
java -jar target/wisdom-farm.jar
```

启动成功日志：
```
Started WisdomFarmApplication in x.xxx seconds
```

默认端口：**8080**

## 二、环境变量说明（.env）

### 必填项

```env
# 数据库
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=wisdom_farm

# JWT 密钥（生产环境务必修改！）
JWT_SECRET=至少32位的随机字符串

# 微信小程序
WECHAT_APPID=你的小程序AppID
WECHAT_SECRET=你的小程序AppSecret
```

### 微信支付联调必填

```env
# 商户号
WECHAT_PAY_MCH_ID=商户号

# 商户证书序列号
WECHAT_PAY_SERIAL_NO=32位十六进制序列号

# API私钥（二选一）
WECHAT_PAY_PRIVATE_KEY=完整私钥内容含头尾
# 或 WECHAT_PAY_PRIVATE_KEY_PATH=/path/to/apiclient_key.pem

# API v3 密钥
WECHAT_PAY_API_V3_KEY=32位密钥字符串

# 回调地址（公网HTTPS）
WECHAT_PAY_NOTIFY_URL=https://你的域名/api/pay/notify/wechat
```

### 获取微信支付参数步骤

1. 登录 [微信支付商户平台](https://pay.weixin.qq.com)
2. **账户中心 → 商户信息** → 获取商户号 (mchId)
3. **账户中心 → API安全** → 申请 API 证书 → 下载私钥文件
4. 同页面查看 **证书序列号** 和 **APIv3密钥**
5. **账户中心 → API安全** → 下载 **平台证书/公钥**

## 四、小程序端配置

### 4.1 baseURL 设置

编辑 `miniapp/utils/request.js`：

```javascript
const BASE_URL = 'http://localhost:8080'  // 本地开发
// const BASE_URL = 'https://your-production-domain.com'  // 生产环境
```

### 4.2 请求格式

所有接口统一返回格式：

```json
{
  "code": 0,        // 0=成功，其他=错误码
  "msg": "success",
  "data": { ... }   // 业务数据
}
```

### 4.3 认证方式

```javascript
// 登录后获取 token，存入缓存
wx.setStorageSync('token', res.data.data.token)

// 后续请求携带 Header
header: {
  'Authorization': 'Bearer ' + wx.getStorageSync('token')
}
```

## 六、常见错误码

### 6.1 HTTP 状态码

| 状态码 | 含义 | 常见原因 |
|--------|------|----------|
| **401** | 未认证 | Token 缺失、过期、无效 |
| **403** | 无权限 | 非管理员访问管理接口、角色不足 |
| **500** | 服务器内部错误 | 数据库异常、参数校验失败 |

### 6.2 业务错误码 (code 字段)

| code | 含义 | 解决方案 |
|------|------|----------|
| 0 | 成功 | - |
| 1001 | 参数错误 | 检查请求体字段是否完整 |
| 1002 | 记录不存在 | 检查 ID 是否正确 |
| 1003 | 状态冲突 | 如取消非待支付状态的订单 |
| 2001 | 微信登录失败 | 检查 AppID/AppSecret 配置 |
| 2002 | 支付创建失败 | 检查微信支付配置是否完整 |
| 3001 | 权限不足 | 需要 SUPER_ADMIN 角色 |
| 3002 | 账号已禁用 | 联系超级管理员 |

### 6.3 排查指南

**401 错误：**
```javascript
// 1. 检查 token 是否存在
const token = wx.getStorageSync('token')
if (!token) { wx.navigateTo({ url: '/pages/login/login' }) }

// 2. 检查 token 是否过期（默认7天）
// 重新调用 /auth/wx-login 获取新 token

// 3. 检查 Header 格式
header: { 'Authorization': 'Bearer ' + token }
```

**403 错误：**
```
// 管理员接口需要 admin token，不是用户 token
// 先调用 /auth/admin-login 获取管理员 token
```

**500 错误：**
```
// 1. 查看后端控制台日志
// 2. 检查数据库连接是否正常
// 3. 检查 .env 配置是否正确加载
```

## 七、微信支付联调流程

### 7.1 完整支付流程

```
小程序端                    后端                   微信支付服务器
   |                          |                        |
   |-- POST /pay/create ----->|                        |
   |   {type:"CLAIM",         |--- 创建支付订单 ------->|
   |    bizId:1}               |   返回 prepay_id         |
   |<-- 返回 wxPayParams -----|<------- 返回 ------------|
   |                          |                        |
   |-- wx.requestPayment ---> |                        |
   |   (拉起微信支付)          |                        |
   |                          |                        |
   |                          |<-- POST /pay/notify --|
   |                          |    (异步回调通知)       |
   |                          |--- 更新支付状态 -------->
   |                          |                        |
   |-- GET /pay/status/{id} ->|                        |
   |<-- 返回最新状态 ---------|                        |
```

### 7.2 本地调试支付

由于微信支付回调需要 HTTPS 公网地址，本地开发需要内网穿透：

```bash
# 使用 ngrok 示例
ngrok http 8080
# 获得 https://xxxx.ngrok.io

# 设置 .env
WECHAT_PAY_NOTIFY_URL=https://xxxx.ngrok.io/pay/notify/wechat
```

## 九、注意事项

1. **首次部署**：必须执行 `docs/database.sql` 初始化数据库
2. **密码安全**：默认管理员密码为 `admin`，上线前务必修改
3. **JWT 密钥**：生产环境使用强随机字符串，定期轮换
4. **微信支付**：回调地址必须是 HTTPS，且能被微信服务器访问
5. **CORS 配置**：开发环境下已允许跨域，生产环境需配置域名白名单
6. **Mapper 一致性原则**：修改 Entity/VO 时必须同步更新 Mapper XML
